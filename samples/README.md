# Samples

Boot Sequence's drum kit and hits are one-shots from Sonic Pi
(https://github.com/sonic-pi-net/sonic-pi/tree/dev/etc/samples), which are public domain (CC0); no attribution is
required, but credit is given anyway.

| File | Played as |
|---|---|
| `bd_haus` | kick |
| `sn_dolf` | snare |
| `perc_snap` | clap |
| `drum_cymbal_closed`, `drum_cymbal_open` | hats |
| `drum_splash_hard` | crash (also reversed into the drops) |
| `perc_impact1` | drop impact |
| `vinyl_backspin` | the power cut before the peak |
| `elec_blip` | the telegraph guest |
